# Shooting with Shapes
This is a game where you must protect your spaceship from attacking enemies as you travel to a far-away planet to bring back coveted stars for your homeland. The game contains 24 levels of increasing length and difficulty.
## Gameplay
The game takes place on a hexagonal spaceship with 6 shapes of ammo and 6 shapes of launchers. Enemies gradually approach the spaceship and, to defeat them, the player must bring the ammo whose shape matches the enemy to the corresponding launcher, and click to shoot it at the enemy. As the player unlocks more levels, new enemy types will appear, which take multiple hits to defeat.
## Stardance challenge
This game was made partially for the Hack Club Stardance challenge. The base of the game was made before the challenge, but the multiple enemy types, music, sound and visual effects, and other aspects were made for this challenge. That was also when this repository was made, so any change in a commit is new since the start of the challenge.
